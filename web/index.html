What this shell does

      

      

        The shell loads the ZWASM container, verifies its header/index, reads entries lazily,
        lists browser-ready boot/image metadata, and provides the host UI. A package is not
        treated as a native Windows executable: a usable browser game must include a prepared
        boot module and an accompanying host contract.
